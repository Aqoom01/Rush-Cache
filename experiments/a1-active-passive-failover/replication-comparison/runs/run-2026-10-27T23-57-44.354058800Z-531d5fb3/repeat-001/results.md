## 해석과 한계

- 전원 ACK 대기이므로 느린 Backup의 추가 ACK 지연이 응답 시간에 반영된다.
- 기대 완료 시간은 2 × 단방향 지연 + 추가 ACK 지연이다. deadline 이상이면 TIMEOUT이다.
- TIMEOUT은 롤백이 아니다. 늦은 메시지를 모두 전달한 후 일부 복제본의 값이 남는 경우를 별도 집계했다.
- 각 요청 후 timer·늦은 메시지를 모두 배출한다. 연속 부하·timeout 직후 재시도·처리량 실험이 아니다.
- 고유 키와 고정 지연, 즉시 로컬 처리 모델이다. 반복은 재현 확인이며 성능 분산 표본이 아니다.
- success_ms=-1은 성공 요청 없음이다. 실제 서버 성능·failover·분단 안전성은 측정하지 않았다.
