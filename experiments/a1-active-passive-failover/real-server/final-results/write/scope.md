# 해석 범위

- write는 매 실행 새 JVM/로그의 제한된 구간이다. 장시간 steady-state·최대 처리량이 아니다.
- p99는 실행별 원본 표본에서 구한 값의 중앙값/min/max다. 합산 p99나 신뢰구간이 아니다.
- crash는 sendall 후 응답 전 종료이며 서버 내부 commit 시점을 강제하지 않는다.
- read는 clean read-only 부하이며 혼합 부하의 선형화가능성 검증이 아니다.
- 부하 발생기를 노드와 함께 실행한다. 1 vCPU에서는 발생기 경합도 측정에 포함된다.
- 반복으로 관측 범위를 늘렸을 뿐 운영 성능/모든 장애의 안전성을 증명하지 않는다.
