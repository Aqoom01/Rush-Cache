본실험은 CORE_FOCUS_PLAN.md의 EC2 계획으로 전환했다. 로컬은 36회 완료 후 중단했고 모든 소유 JVM을 정리했다. 아래는 당시 계획 기록이다.

# 24시간 이내 핵심 통합 비교

2026-11-13 사용자 요청: 남은 시간24시간 안에서 핵심 실험 우선. 로컬 공유 호스트를 사용하며 EC2·독립 디스크 성능으로 일반화하지 않는다. 모든 실행은 A1 승인/소유권 + A2 데이터 복제와 A3 및 B1~B3를 포함하는 joint cache다.

## 먼저 실행하는 비교

- 기준선 예비 측정: RAFT + O00, F3,2그룹,128keys,1KiB,읽기80%,동시64. rate100/300/1000,각15초 측정. 실제 기록은 `runs/core-24h-pilot-20261113/summary.json`.
- A1×A2: A1 7개 × A2 읽기 정책 포함9변형 × seed2개 =126회. 순서를 고정 seed로 섞고 한 번에 한 조합만 실행한다.
- 공통 조건: F3 기본 프로필, RANGE/NONE/NONE, fixed/fifo/PRE/preflight-all, active2그룹. HOT_RANGE,128keys,1KiB,읽기80%,동시64,rate1000,5초 워밍업+30초 측정. 개별 JVM startup·prefill·audit·cleanup은 측정시간 밖이지만 wall time에 포함한다.
- 1000req/s는 기준선의 과부하 지점이다. 미수락·실패를 숨기지 않고 지연과 함께 비교한다. 빠른 성공 요청만 골라 승자를 선정하지 않는다. 정상 상태의 대조 rate300은 후보 정밀 검사에 사용한다.

## 후보를 얻은 뒤

0. 작은 데이터셋에 대한 편향을 확인하기 위해,RAFT/VR 계열 후보의 A1을 고정하고 A2 9변형 × 새 seed3개를8,192keys·4KiB·60초 측정으로 비교한다. history.target.entries=4,096보다 큰 작업 집합이다. 기존 소규모와 값 크기·측정 시간이 다르므로 크기의 단일 인과 효과를 계산하지 않고,동일한 확대 조건 내 A2끼리 비교한다. 결과가 다르면 최종 후보를 다시 검토한다. 파일은 로컬 page cache의 영향을 받으며 실제 SSD 하드웨어 비교로 주장하지 않는다.
1. 후보와 기준선을 rate300/1000,더 긴 측정 구간,새 seed3개로 재검증한다. 최대 성공 비율과1%p 이내인 후보 중 p99가 낮은 조합을 후보로 고른다. 잘못된 값·요청 실패·정상 프로세스 DOWN이 관측된 조합은 후보에서 제외하고 원본을 보존한다. 일반 후보와 RAFT/VR 계열 후보를 함께 고르며 baseline도 재측정한다. 같은 조건의 요청 tape가 일치해야 직접 비교한다.
2. 후보 조합에서 STOP/PRE/POST와 대표 B1/B2 재배치 정책을 실제 SCALE_CYCLE로 비교한다. scheduler/copy 선택은 실제 이동이 있었는지 확인한다.
3. 주요 FD5개를 이동 중 실제 JVM 종료로 비교한다. 제품 기본 timeout을 유지하고 복구 이후까지 측정한다. 현재1초 고정 pause로 느린 FD를 평가하지 않는다.
4. 자동 증감 정책은 실제 모델 보정·관찰 자료가 있는 후보에서 별도로 비교한다. 자료가 없는 학습 정책을 임의 값으로 채우거나 TRAINING을 정책 성공으로 집계하지 않는다.

스크리닝으로 고른 후보에서 조건부 권장 조합을 제시한다. B전체·고차 상호작용을 전수 실행하거나 절대적인 최적 조합을 증명했다고 말하지 않는다. 목표 wall time6~8시간은 최초 추정이며 실제 행별 시간·실패에 따라 재산정한다. 실패는 원본과 함께 보존하고 cleanup 실패 시 다음 실행을 멈춘다.

## 기록과 판정

`runs/core-24h-20261113/`에 입력 CSV,구동 명령·시각·driver/controller/JAR SHA,원본 요청·상태·이동·fault·cleanup을 보존한다. 소유 JVM 정리 실패는 즉시 중단 조건이다. 정합성·joint 실행·FD·이동 검증이 실패한 실행을 성능 승자로 선정하지 않는다. 요청 실패·미수락·live-process DOWN도 별도 지표로 남긴다. 반복별 결과와 조건을 함께 보고하며,seed2개로 얻은 작은 차이는 확정 순위로 표현하지 않는다.
